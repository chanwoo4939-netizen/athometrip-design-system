Motion

움직임의 시간과 가속, 쓰는 곳.

Motion
Overview Duration Easing Usage Loading Reduced motion

Overview

움직임은 무엇이 바뀌었는지 알리는 데 씁니다. 상태가 바뀔 때, 새 내용이 나타날 때, 내용을 기다릴 때 세 가지입니다.

쓰임예시간
상태가 바뀔 때Hover, Pressed, Focus, Selected0.15초
새 내용이 나타날 때나타나기, 옆에서 들어오는 패널, 배너 넘김0.3초 ~ 0.8초
내용을 기다릴 때Skeleton, Spinner1초 ~ 2초 반복
  • 누른 것에 대한 반응은 0.3초를 넘기지 않습니다.
  • Hover에서는 색과 불투명도만 바뀝니다. 크기와 위치는 움직이지 않습니다.

Duration

움직이는 거리가 길수록 시간을 길게 씁니다.

시간쓰는 곳
0.15초색, 불투명도, 테두리, 그림자가 바뀔 때. 기본값
0.2초제휴사 배너 아래 점
0.3초나타나기, 옆에서 들어오는 패널, 진행 막대, 메인 배너 아래 점
0.8초메인 배너 넘김
1초Spinner 한 바퀴
2초Skeleton 한 번 깜빡임

Easing

가속은 네 가지입니다. 따로 정하지 않으면 기본을 씁니다.

이름값쓰는 곳
기본cubic-bezier(.4, 0, .2, 1)상태 변화, 진행 막대
들어올 때cubic-bezier(0, 0, .2, 1)옆에서 들어오는 패널
배너 넘김cubic-bezier(.16, 1, .3, 1)메인 배너
일정한 속도linearSpinner, 흐르는 띠

Usage

새 내용은 들어오는 방향에서 짧게 움직이며 나타납니다.

나타나기0.3초, 아래 10px에서
옆에서 들어오는 패널0.3초, 오른쪽에서
메인 배너 넘김0.8초
흐르는 띠일정한 속도로 반복
움직임시간과 가속모양
상태 변화0.15초, 기본색, 불투명도, 테두리, 그림자만 바뀜
나타나기0.3초, ease-in-out아래 10px에서 올라오며 불투명도 0에서 100%
옆에서 들어오는 패널0.3초, 들어올 때화면 오른쪽 밖에서 제자리로
메인 배너 넘김0.8초, 배너 넘김3초마다 다음 장으로 넘어감
진행 막대0.3초, 기본막대 길이가 늘어남
흐르는 띠일정한 속도제휴사 로고는 50초에 한 바퀴, 글자 띠는 18초 ~ 20초에 한 바퀴
  • 사라질 때는 나타난 길을 되돌아갑니다.
  • 여러 요소를 한꺼번에 움직이지 않습니다. 한 번에 한 가지만 움직입니다.

Loading

기다리는 동안에는 같은 움직임을 일정하게 되풀이합니다. 모양은 State의 Loading에 있습니다.

Skeleton2초에 한 번
Spinner1초에 한 바퀴
종류시간과 가속움직임
Skeleton2초, cubic-bezier(.4, 0, .6, 1), 반복불투명도 100%에서 50%로 갔다가 돌아옴
Spinner1초, 일정한 속도, 반복시계 방향으로 한 바퀴

Reduced motion

기기에서 움직임 줄이기를 켠 사람에게는 움직임을 줄여서 보여 줍니다.

  • 되풀이되는 움직임은 멈춥니다. 흐르는 띠와 자동으로 넘어가는 배너가 해당합니다.
  • 위치가 움직이는 것은 불투명도만 바뀌게 합니다.
  • 상태 변화처럼 색만 바뀌는 것은 그대로 둡니다.
